1Life Q.A Task Dashboard • User Guide & Documentation

Website Documentation — What, Why & How to Use

Complete reference guide for the 1Life Data Analytics Q.A. Task Monitoring & Waybill Operations Dashboard.

1

What is the 1Life Q.A Task Dashboard?

The 1Life Q.A Task Dashboard is the centralized analytics and monitoring portal for the 1Life Data Analytics Q.A. Team. It consolidates live records from our two master Google Spreadsheets into interactive KPI scorecards, visual charts, searchable tables, and one-click Excel (.xlsx) and PDF (.pdf) reports:

  • QA Task Monitoring Sheet (1CiVJpYv00...): Pharmacy, Daily Waybill Log, Invalid Waybills, Account Merging, IT Schedule Monitoring, Output QA, and Dispatch.
  • Waybill Master Validation Sheet (1l_WgHYJno...): End-to-end Initial QA, Dispatch Overrides, Final QA, and RTH defect remarks.
2

Why Use This Dashboard?

  • Single Source of Truth: Eliminates manual counting across 9+ spreadsheet tabs by automatically syncing live Google Sheets data.
  • Accurate Defect & Rider Attribution: Counts each invalid waybill strictly once (single-document or multi-document defect) so totals match actual invalid waybill volume.
  • Readable Stakeholder Reports: Generates formatted multi-tab Excel workbooks and clean landscape PDF reports without congested spreadsheet charts.
  • Corporate Security: Protected by Google Workspace OAuth 2.0 so only verified @1life.ph company accounts can access the workspace.

3. How to Use Each Section

Navigate between modules using the left sidebar

Home (All Tasks)

Displays summarized KPIs across all 5 QA task streams, your 14-day hours chart, and the interactive 7-Tab Spreadsheet Explorer to search or export raw tabs.

Task Log

Shows every Time In (Started) and Time Out (Ended) across all QA tasks with visual hours charts, plus the Daily Waybill Quota Log and Pharmacy Monitoring tables.

RTH Notes

Dedicated Return-to-Hub (RTH) invalid document audit hub. Filter by date cycle, document (ID, MDC, RC, LOA), or rider, and export RTH Excel/PDF reports.

Waybill & Dispatch Dashboards

Filter by Validation Date, QA Specialist, or Dispatch Specialist to inspect lifecycle conversion funnels, throughput trends, override velocity, and individual waybill audit modals.

Account Merging, Output QA & IT Schedule

Focused dashboards for monitoring barangay/municipality merging audits, Data Team report/dashboard QA pass rates, and IT schedule linking runs.

Live Sync, Theme & Exports

Click Sync Sheets in the top bar for fresh Google Sheets data, switch Light/Dark Blue theme via your bottom-left profile menu, and export any view to .xlsx or .pdf.
